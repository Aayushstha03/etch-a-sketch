Etch-A-Sketch

Etch A Sketch App Features

  • Color Selection: Choose from Red, Yellow, Green, Blue, Dark, White, and Rainbow to draw with different colors.
  • Eraser: Use the eraser tool to remove color from tiles.
  • Bucket Fill: Fill an entire area of connected tiles with the selected color using the bucket fill tool.
  • Mirror Drawing: Enable mirror X or Y axis to draw symmetrical patterns automatically.
  • Board Resize: Change the board size to your preference (up to 64x64) for more or less drawing space.
  • Reset: Clear the board and start fresh at any time.
  • Screenshot: Download your current drawing as an image file.
  • Click & Drag Drawing: Hold down the mouse button and drag to draw continuously.
  • Rainbow Mode: Draw with randomly changing colors for a fun effect.

Experiment with the tools and create your own pixel art!
